# Plan: Image Pipeline Infrastructure

## Summary

Implement an explicit Node ESM pre-build pipeline around Sharp, SVGO and real native metric CLIs. A small source registry maps future verified PNG masters to current logical asset paths. Export a pure typed source-set helper without activating it in the UI.

### 3. Registry, master guard and generation policy

Registry shape: `{ schemaVersion: 1, sources: [{ sourcePath, masterPath, class, profile, targetWidth? }] }`; bootstrap `sources: []`.

- `sourcePath` is an existing logical local path under `content/assets/`; `masterPath` is under `content/assets-masters/`; class is `a|b|c`; profile is `text|photo`. Require exact POSIX-relative safe paths, no URL/query/fragment/backslash/empty/dot/parent segments, duplicates or symlinks. Validate registered logical source existence; fixtures supply their own logical originals.
- Every regular file discovered under masters is a registered input; no README/metadata/JPEG sidecar inside the master root. Check `.png` case-insensitively, byte MIME `image/png` via `file-type`, Sharp format `png`, positive finite dimensions and successful full decode. Reject animated/multipage PNG and nontrivial orientation until deliberately supported. Corrupt header-only inputs must not pass `metadata()` alone.
- Normalize decoded pixels to 8-bit sRGB and flatten alpha on white for all three derivatives and their reference; document this as codec policy rather than implicit JPEG-only alpha loss. Never mutate/rewrite master bytes. Master SHA is over original bytes.
- Width set: configured widths not exceeding source width; if that set is empty use the source's natural width. Height is a deterministic positive rounded aspect-ratio height. Both generation and reference use these explicit dimensions with `fit: fill`, `lanczos3`, `withoutEnlargement: true`; recheck actual decoded output dimensions.
- Photo baseline: AVIF quality 55, effort 4, 8-bit, `4:2:0`, explicit `tune: iq` (D-011); WebP quality 82, effort 4; JPEG quality 82, mozjpeg, progressive, `4:2:0`.
- Text baseline: AVIF quality 70, effort 4, 8-bit, `4:4:4`, explicit `tune: iq` (D-011); WebP quality 90, effort 4; JPEG quality 90, mozjpeg, progressive, `4:4:4`.
- Each encoder uses an independent Sharp clone/buffer; strip metadata. Restrict concurrent masters to a small bounded count such as `min(4, availableParallelism)`; allow `--concurrency` only within a validated bounded range and do not serialize it into content identity.
- Optional registry target width is enforced against the largest actually produced variant. Do not infer that full retina coverage passed when registry is empty or a target is omitted; report omission explicitly. Later stages supply real per-container targets/provenance.

### 4. Canonical manifest and incremental integrity

Manifest shape: `{ schemaVersion: 1, policy, policySha256, sources: [...] }`; bootstrap has the exact current policy and `sources: []`. Use imported `canonicalJson` plus a single newline; no wall-clock fields, absolute paths, mtime, timing or status chatter in canonical bytes.

Policy includes widths, format/profile encoder settings, normalization, reference kernel/fit, thresholds/retry/sample algorithm, schema/pipeline version and pinned/actual tool versions. For nonempty outputs bind installed Sharp/encoder versions (`sharp.versions` relevant codec/vips fields), native DSSIM and SSIMULACRA2 versions; SVG evidence separately binds SVGO/config hash and actual renderer versions. Use portable pinned version identity, excluding platform/architecture/compiler paths and incidental build metadata: equivalent bytes on macOS/Ubuntu/Alpine must validate read-only without editing evidence. Record those platform details in task verification evidence. If an actual relevant codec/renderer version differs, report it for Architect disposition instead of silently accepting or rewriting audit identity. An empty bootstrap can declare pinned policy without claiming native measurements.

Source record: `{ sourcePath, masterPath, class, profile, sourceSha256, masterWidth, masterHeight, generationSha256, targetWidth?, variants: [...] }`.

Variant record: `{ width, height, format: avif|webp|jpeg, path, sha256, bytes, quality, attempt: 1|2, qa: { referenceWidth, referenceHeight, kernel: lanczos3, dssim, ssimulacra2? } }`. Sort source records by source path and variants by width then fixed format order. `generationSha256` binds source bytes, registry semantics, current policy/config/tool identity. Path suffix matches first eight hexadecimal characters of the full actual derivative SHA.

- Reuse is admitted only after exact source/registry/current-policy match, complete unique expected width/format set, safe expected owned paths, full bytes/hash/format/MIME/dimension checks and real quality recomputation. Never trust stored passing scores, mere existence or mtime.
- Validator rejects extra/missing sources/variants, reordered/duplicate records and stale policy/generation identities; actual AVIF may be reported by Sharp as HEIF, so verify AV1 compression + byte MIME `image/avif`, not a mistaken `format === avif` assumption.
- Build may regenerate a missing/corrupt old variant into a new verified owned output; validator fails on it until rebuilt. `--write` evidence refresh does not regenerate or adopt tampered variants.
- Write new files through confined scratch paths; publish manifest/evidence only after all gates pass. Never overwrite an existing hash URL with differing bytes, follow a symlink or delete unrelated outputs. Keep old immutable hashed files; pruning is deferred. A hash8 collision fails with explicit full-hash evidence.
- Source/old output hashes are read afresh for every run; previous evidence is not proof of current bytes. Test unchanged-run byte identity, stale policy, source change, output tamper, missing variant and forged QA records.

### 5. Real metrics and deterministic retry/sample

Shared `measureLikeSizedQuality` prepares the reference once from current verified master pixels at the candidate's actual width/height. Decode candidate to PNG without resizing; assert candidate/reference dimensions match and candidate fits within master before invoking tools by argument arrays, never a shell command string.

- Run pinned `dssim <reference.png> <candidate.png>`; parse one finite nonnegative score. Require DSSIM `<= 0.01` for every derivative.
- Choose SSIMULACRA2 sample by sorting variant keys on SHA-256 of `sourcePath|width|format`, lexical key as a collision tiebreak, then take `max(1, ceil(totalVariants * 0.05))` for nonempty corpus. A changed corpus recomputes the exact sample. Run `ssimulacra2_rs image <reference.png> <candidate.png>` and require a finite score `>= 70`. Reuse/validator run the same sample, not a random or stored list.
- If a candidate fails either applicable gate, encode from the same prepared source once more with `min(100, baselineQuality + 5)`; remeasure and use only that result if it passes. No second quality increase, metric substitution, reference distortion or candidate enlargement. All other settings stay fixed; record quality/attempt. A second failure aborts that build before manifest publication. Unit-test retry control with injected runner plus real integration showing baseline quality and deliberate rejection; injected runners never replace all real metric tests.
- Validator independently recomputes thresholds. Audit scores are not required to compare bit-exact across different CPU platforms, but finite numbers/allowed retry settings/reference dimensions/current-policy identity are structural requirements and actual scores must pass every time. Document installed versions and observed scores in verification evidence.
- Temporary reference/candidate PNGs stay in isolated task scratch and are removed by the creating operation; no local-worktree cleanup authority is implied.

### 8. Typed browser helper

Keep pure types/logic in `src/data/imageAssets.ts` so existing node tests can transpile/import it like `tests/domain.test.mjs`; inject manifest into the pure helper. `src/data/content.ts` imports the committed JSON and re-exports its manifest-bound `assetSrcSet(sourcePath)`.

Return shape:

```text
{ avifSrcSet: string, webpSrcSet: string, jpegSrcSet: string,

```

`srcSet` is the JPEG set for backward-compatible generic usage; choose the largest JPEG as fallback and use that exact candidate's dimensions. ## Architect Dispositions Of Proposal Tensions

1. **D-001 — source-preserving SVG scope accepted.** Canonical in-place SVGO would break reviewed pins and stage-1 no-visual-change intent. Process the entire real learning corpus into derived/audit outputs instead. Keep all current UI paths/pins. Four manual SVGs remain governed; absent class (e) is explicitly reported. This is the recorded interpretation, not an unreported skip.
2. **D-002 — removeDimensions rejected.** Existing SVG governance requires intrinsic width/height, and future use should preserve sizing. Retain dimensions/viewBox/title/IDs/styles; safe config and real sample prove output, not source-pin changes.
3. **D-003 — quality +5 retry accepted.** Exactly one deterministic retry from the same source/reference for a failed codec, bounded to 100, with attempt/quality evidence and second-failure abort. No arbitrary adaptive loop.
4. **D-004 — SSIMULACRA2 sample accepted now.** Keep the 5% gate `>=70` using the published pure-Rust still-image CLI, with a deterministic hash sample instead of random sampling. It remains real and runnable in macOS/Linux/Alpine; no expensive libjxl/video toolchain is needed. If the locked CLI cannot build, Architect must explicitly dispose that feedback before implementation diverges.
5. **D-005 — empty raster corpus accepted honestly.** Commit empty registry/manifest and verify real PNG codec/metric fixtures; report no production raster measurement. Do not invent masters, transcode JPEG as source recovery, or claim later retina/traffic targets.
6. **D-006 — deterministic outputs with platform identity.** Byte-repeat guarantee applies to unchanged inputs and the recorded policy/encoder versions on an effective toolchain. Actual encoder/renderer identity invalidates cache after change; validator still recomputes current gates. Cross-CPU score equality is not an acceptance condition.
7. **D-007 / IF-001 — scoped SSIMULACRA2 lock repair required.** Retaining the published lock is rejected. Selected still-image graph contains bytes 1.6.0 in the affected range of [RUSTSEC-2026-0007](https://rustsec.org/advisories/RUSTSEC-2026-0007.html), and bytemuck 1.16.0 whose [upstream changelog](https://raw.githubusercontent.com/Lokathor/bytemuck/main/changelog.md) documents BoxBytes UB fixed in 1.16.2. Local selected-tree/source inspection has not established exploitation through our normalized PNG CLI path; that uncertainty is not a reason to retain known affected versions. Crossbeam-channel 0.5.13 is absent from the `--no-default-features` normal/build tree but present in the full lock and affected by [RUSTSEC-2025-0024](https://rustsec.org/advisories/RUSTSEC-2025-0024.html); repair the optional entry too. Spin 0.9.8 already fixes [RUSTSEC-2023-0031](https://rustsec.org/advisories/RUSTSEC-2023-0031.html); no new vulnerability is inferred from its yank. All four replacement exact versions are non-yanked in the primary sparse registry. This is an implementation task, with no metric waiver or broad tool upgrade. Completion requires reviewed lock/checksums, clean selected dependency tree, native equal/degraded fixtures and real macOS/Ubuntu/Alpine validation; route incompatibility or extra OSV findings back to Architect.
