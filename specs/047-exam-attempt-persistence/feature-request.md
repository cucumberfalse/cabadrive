## Цель

Экзаменационная попытка перестаёт быть источником молчаливой потери данных: пользователь осознанно начинает попытку с экрана формата (таймер до этого не идёт), а начатая попытка переживает перезагрузку страницы и переключение вкладок и может быть корректно продолжена с правильным остатком времени и сохранёнными ответами; уход с вкладки экзамена или закрытие браузера при активной попытке требует явного подтверждения. Ноль сценариев, где случайный клик, обновление или переключение вкладки безвозвратно уничтожают ход экзамена.

## Scope

В scope (ровно три функциональных требования слайса 2 ТЗ-P1, уточнённые под текущий код):

- **FR-B1 (стартовый экран экзамена).** До начала попытки вкладка «Экзамен» показывает стартовый экран-карточку с форматом, взятым из `data.examFormat`: количество вопросов, лимит времени, проходной балл, правила пропуска (`canSkipQuestion`), пометка `status`. Кнопка «Начать» переводит в активную попытку. **Таймер и отсчёт времени не запускаются, пока пользователь не нажал «Начать»** — набор вопросов и `startedAt` фиксируются в момент старта, не на маунте компонента.
- **FR-A4 (персист активной попытки).** В момент старта и при каждом ответе активная попытка сериализуется в localStorage под ключом `cabadrive.exam-attempt.v1` в форме `{ questionIds, answers, startedAt, deadline }`, где `deadline` — абсолютный timestamp `startedAt + data.examFormat.timeLimitMinutes*60_000`. При возврате на вкладку/после перезагрузки, если валидная непросроченная попытка сохранена, пользователю предлагается «Продолжить попытку (осталось MM:SS)» / «Отменить»; продолжение восстанавливает набор вопросов, ответы, позицию и **остаток времени, вычисленный из абсолютного `deadline`** (а не из «замороженного» remaining). «Отменить» очищает сохранённую попытку. Завершение попытки (`finish`) очищает ключ. (Восстановление таймера из `deadline` — часть FR-A4 и в scope; изменения цвета/aria таймера FR-B3 — НЕ в scope.)
- **FR-A5 (guard ухода и закрытия).** При активной (начатой, незавершённой) попытке: попытка уйти с вкладки «Экзамен» на другую вкладку открывает подтверждающий `ConfirmDialog` (переиспользуя компонент слайса 1); подтверждение уводит с вкладки (сохранённая попытка остаётся для последующего «Продолжить»), отказ оставляет на экзамене. Закрытие/перезагрузка вкладки браузера при активной попытке вешает нативное предупреждение через `beforeunload`. `beforeunload` — дополнительная страховка; основная гарантия сохранности — персист FR-A4 (в мобильных браузерах `beforeunload` ненадёжен — ТЗ-P1 §10).
- Доступность диалога по NFR-3 ТЗ-P1: фокус-ловушка, `Esc`, автофокус на безопасной кнопке (наследуется от `ConfirmDialog`); новые интерактивные элементы (кнопка «Начать», кнопки notice-панели) соответствуют паттернам `focus-visible` и touch-таргетам ≥42 px (NFR-2).

## Функциональные требования

1. Вкладка «Экзамен» до старта попытки показывает стартовый экран с форматом из `data.examFormat` (число вопросов, минуты, проходной %, правила пропуска, `status`) и кнопкой «Начать»; никакие литералы 40/45/85 не хардкодятся.
2. Ни таймер, ни отсчёт времени, ни фиксация `startedAt` не происходят до нажатия «Начать»; набор экзаменационных вопросов фиксируется в момент старта.
3. При старте и при каждом ответе активная попытка персистится в localStorage под ключом `cabadrive.exam-attempt.v1` в форме `{ questionIds, answers, startedAt, deadline }` с `deadline = startedAt + data.examFormat.timeLimitMinutes*60_000` (абсолютный timestamp).
4. При возврате на вкладку экзамена или после перезагрузки, если сохранена валидная непросроченная попытка, показывается предложение «Продолжить попытку (осталось MM:SS)» / «Отменить»; MM:SS вычисляется из `deadline` относительно текущего времени.
5. «Продолжить» восстанавливает `questionIds`, `answers`, позицию и остаток времени, рассчитанный из абсолютного `deadline`; продолженная попытка ведёт себя как непрерванная (в т. ч. корректно финиширует по таймеру и по последнему ответу).
6. «Отменить» (отказ от продолжения) очищает ключ `cabadrive.exam-attempt.v1`; успешное завершение попытки (`finish`) также очищает ключ — завершённая попытка живёт только как запись `examAttempts` в прогресс-store.
7. При активной попытке уход с вкладки «Экзамен» на другую вкладку открывает `ConfirmDialog`; подтверждение уводит (персист попытки сохраняется), отказ/Esc/клик мимо оставляют на экзамене.
8. При активной попытке закрытие/перезагрузка вкладки браузера инициирует нативное `beforeunload`-предупреждение; при отсутствии активной попытки `beforeunload` не навешивается.
9. Персист попытки изолирован в отдельном модуле с `StorageLike`-приёмником и `try/catch` (по образцу `src/progressResetSafety.ts`); UI не обращается к `localStorage` напрямую по строковому ключу вне этого модуля.
10. Диалог guard доступен с клавиатуры (фокус-ловушка, Esc, автофокус на безопасной кнопке — из `ConfirmDialog`); кнопка «Начать» и кнопки notice соответствуют touch/focus-паттернам приложения.

## Негативные сценарии (обязательные для feature memory)

- **localStorage недоступен / private mode / квота (главный негативный сценарий цикла):** персист активной попытки молча деградирует (обёрнут в `try/catch` по образцу `progressResetSafety.ts`), но экзамен полноценно запускается и проходится в памяти без падения — просто без гарантии восстановления после перезагрузки. Приложение не крашится, ошибка не всплывает пользователю как сбой.
- **Битая / несовместимой версии сохранённая попытка:** нечитаемый JSON, отсутствующие/некорректные поля (`questionIds`/`answers`/`startedAt`/`deadline`), неизвестные `questionIds` (не найдены в текущем пуле) → сохранённая попытка отбрасывается и ключ очищается; пользователь видит чистый стартовый экран, а не «восстановление» в сломанное состояние.
- **Просроченная попытка (`deadline <= now`):** при возврате не предлагается к продолжению, а отбрасывается (ключ очищается); никакого продолжения с отрицательным/нулевым остатком.

- **Уход с вкладки при активной попытке** не теряет прогресс молча: либо пользователь подтверждает уход и попытка остаётся сохранённой для продолжения, либо остаётся на экзамене (следствие FR-A5 + FR-A4).
