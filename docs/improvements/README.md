# Бэклог доработок Cabadrive

Результат полного аудита репозитория от 2026-07-11: многоагентный анализ по подсистемам и измерениям качества (архитектура, UX, PWA/оффлайн, контент, изображения, тестирование, CI, инфраструктура, документация) с проверкой каждого утверждения по коду и точечными измерениями. Обзор текущего состояния — [00-analysis-overview.md](./00-analysis-overview.md).

Каждое ТЗ самодостаточно: контекст с доказательствами (файлы/строки/замеры), цели и не-цели, требования FR/NFR, дизайн решения, пошаговый план, проверяемые критерии приёмки, риски, затрагиваемые файлы. Приоритеты: **P0** — блокирует/критично, **P1** — ближайшая итерация, **P2** — желательно, **P3** — по возможности. Трудоёмкость: S/M/L/XL.

## Рекомендуемая последовательность

**Этап 1 — критическое (быстрые победы + юридика):**
ТЗ-22 (LICENSE — 1 PR), ТЗ-16 (typecheck/линтер — фундамент для всего дальнейшего), ТЗ-P1 слайсы 1–2 (потеря данных), ТЗ-13 шаг 1 (баги fetch SW), ТЗ-14 (nginx).

**Этап 2 — приоритетные направления владельца:**
ТЗ-P3 этапы 1–3 (инфраструктура пайплайна → фото билетов → страницы учебника), ТЗ-P1 слайсы 3–6 (экзамен, ошибки, роутинг+ТЗ-05, поиск+ТЗ-09), ТЗ-P2 этапы 1–4 (глоссарий, типографика, полнота, spellcheck).

**Этап 3 — платформа:**
ТЗ-06 (store), ТЗ-11 (таймеры), ТЗ-12 (установка PWA), ТЗ-13 (полностью), ТЗ-04 (декомпозиция, параллельно слайсами) + ТЗ-07/ТЗ-08 в её составе, ТЗ-17 (компонентные тесты по мере выноса), ТЗ-10 (code-splitting), ТЗ-P1 слайсы 7–8, ТЗ-P2 этапы 5–6, ТЗ-P3 этапы 4–5.

**Этап 4 — долг и масштабирование:**
ТЗ-15 (iOS), ТЗ-18 (CI), ТЗ-19 (LFS), ТЗ-20 (кросс-платформенная генерация — одной волной с перерендером из ТЗ-P3), ТЗ-21 (скрипты).

Зависимости учтены внутри каждого ТЗ (раздел «Связанные ТЗ»). Главные связки: ТЗ-04 ↔ ТЗ-17 (тесты пишутся на вынесенные модули), ТЗ-P3 ↔ ТЗ-20 (перерендер и смена генератора — одна волна обновления пинов), ТЗ-05 внутри слайса 5 ТЗ-P1, ТЗ-06 до слайсов персиста ТЗ-P1.
